# Security

- Private key lives only in the host environment. Never GitHub, never the page.
- This repo must not contain seeds, passwords, cards, or wallet files.
- The faucet address is public. Treat it as a hot pot. Keep it small.
- Visitors submit a 48-character address only.
- Claims are best-effort. On serverless hosts the disk is ephemeral, so limits live in memory for that instance.
